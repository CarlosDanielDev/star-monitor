# Story — Corpus: fetch the READMEs of the top-30 starred repos

Label: `story`

Parent: #{{EP}}

Fetch the README of each of the 30 most-starred public GitHub repositories
into `corpus/`, with a manifest pinning the query, the day, and each repo's
stars. This corpus is the raw evidence every later issue cites; nothing
downstream re-fetches.

Evidence: GitHub Search API `api.github.com/search/repositories?q=stars:%3E1+fork:false&sort=stars&order=desc&per_page=30` run 2026-10-14 returned 30 repos, first `codecrafters-io/build-your-own-x` (553164 stars), last `tensorflow/tensorflow` (200963 stars). READMEs come from `gh api repos/<owner>/<repo>/readme` with the raw accept header into `corpus/<owner>---<repo>.md` (target paths; manifest at `corpus/manifest.json:1`).

## ADR stub

Fetch via `gh api repos/<owner>/<repo>/readme` (raw accept header) instead of cloning 30 repos: one request per repo, no multi-GB checkouts. Manifest pins query + date so the corpus stays reproducible even though live search results drift day to day. Alternatives rejected: GraphQL (extra scopes for no gain), HTML scraping (fragile).

## Out of scope

- Translated README variants (e.g. freeCodeCamp's) — default English README only.
- Special handling for forks or archived repos.
